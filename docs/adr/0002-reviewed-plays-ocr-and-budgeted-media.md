# Reviewed plays, local OCR, and budgeted media

## Context
The owner authorizes remaining PRD implementation under a strict $0 budget.
Five independent Council analyses, five fresh anonymous reviews and chairman
synthesis were performed. Provider facts came from primary research; consensus
is not verification. Real marked forms, roster content, Hudl rights, hosted
configuration and unlocked-device checks remain unavailable.

## Decision
Plays store user-authored court geometry with stable marker IDs, optional labels
and ordered movement steps. Published revisions are immutable; editing creates
a successor draft. Playback follows saved movement, supports pause/replay/step
navigation and reduced-motion static/discrete positions. Generic marker numbers
are diagram roles, not invented actual roster identities.

Photos use native on-device Vision/PhotosPicker, transient images and raw text
beside reviewable existing-field proposals. Users choose an existing game/player
or possession target and explicitly confirm mappings/values. Unknown notation,
identity and ambiguous values stay unresolved. No source image upload or original
file deletion; OCR text cannot authorize tools, identity, grants or publication.
Actual whole-form mappings/accuracy require representative marked forms.

Private video resources preserve practice versus film identity and review state.
Ordinary active practice contributors can submit pending videos for owner approval;
film eligibility is assigned to coaches/managers through protected grants.
Unrestricted publication bypass is separate from submission eligibility. Explicit
PRD owner-only pending-video approval takes precedence over ambiguous legacy
capability names; delegated grant administration remains bounded. A saved external
link is not proof of provider rights, download, embedding or private playback.

Uploads require trusted type/content/size checks, known available project budgets,
atomic concurrent reservations and reconciliation. Choose an application file
limit below the provider ceiling; fail closed if capacity cannot be established.
Playback admission must account for transfers. No silent deletion, compression
or external transfer; no promise of full-film capacity under Free quotas. Additional
local tooling needs the separately requested approval, not a paid service.

## Consequences
Build independent play, OCR-review and video contracts while provider/device facts
are pending. Label fixtures and distinguish real integration from protocol tests.
Production deployment/public release remains separately approved.
