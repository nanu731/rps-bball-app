Load only the relevant installed skill and necessary references. Project facts and
owner choices win over generic templates. Do not install another library, generate
a competing design system or replace the visual direction merely because a skill
suggests it. New skill versions are optional maintenance, not this task's prerequisite.

For each approved slice: define the task and states, inspect incumbent visual
examples, implement, inspect representative phone/tablet/desktop layouts, repair
observed defects, then verify once more. Test actual touch/keyboard operation,
zoom/reflow, contrast, meaningful labels, reduced motion and loading/error/recovery.
Court tapping needs accessible alternatives and explicit Make/Miss confirmation.
Hide horizontal indicators only while preserving discoverable scrolling and access.

One integrator controls the browser/Simulator. Use Matt Pocock skills for engineering,
ECC for queue/checkpoint discipline and Council for material decisions. Reviewers
are read-only; failed tooling is not proof of an app defect. Native/prototype results
do not establish acceptance of the web implementation. Preserve scoped evidence.
